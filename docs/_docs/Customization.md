## 🎨 Accent Colors & Wallpapers

The repository includes high-resolution Nord wallpapers matched to the theme palette:

```bash
# Apply bundled wallpaper
./scripts/wallpaper.sh
```

You can view the wallpapers in the `wallpapers/` directory of the repo.

---

## ⚓ Dash to Dock Integration

If using Dash to Dock or Ubuntu Dock, pass `--dock` to `./install.sh`. This applies custom Nord glass styling, transparent indicator dots, and matching border radiuses.
