## 🖥️ GNOME Shell

1. Install **GNOME Tweaks** and the **User Themes** extension:
   ```bash
   # Ubuntu / Debian
   sudo apt install gnome-tweaks gnome-shell-extensions
   # Fedora
   sudo dnf install gnome-tweaks gnome-shell-extension-user-theme
   # Arch Linux
   sudo pacman -S gnome-tweaks gnome-shell-extensions
   ```
2. Enable "User Themes" in the Extensions manager.
3. Open **GNOME Tweaks** → **Appearance**:
   - Applications: `Hentai-Senpai-Dark`
   - Shell: `Hentai-Senpai-Dark`

---

## 🌿 Cinnamon

1. Open **System Settings** → **Themes**.
2. Set Window borders, Controls, and Desktop to `Hentai-Senpai`.

---

## 🐭 XFCE

1. Open **Settings** → **Appearance** → Style tab → select `Hentai-Senpai`.
2. Open **Settings** → **Window Manager** → Style tab → select `Hentai-Senpai`.

---

## 🕊️ Budgie & MATE

- **Budgie**: Open **Budgie Desktop Settings** → **Style** → set Widgets to `Hentai-Senpai`.
- **MATE**: Open **Control Center** → **Appearance** → select `Hentai-Senpai`.
