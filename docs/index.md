<p class="eyebrow">Overview</p>
<h2>Dark, elegant, and multi-desktop</h2>
</div>
</div>

<p>
Hentai-Senpai is a beautiful dark GTK theme based on
<a href="https://github.com/vinceliuice/Orchis-theme">Orchis</a> with the elegant
<a href="https://www.nordtheme.com/">Nord</a> color palette.
</p>
<p>
It provides complete theming for GTK 2, 3 and 4, GNOME Shell, window decorations and
docks across multiple desktop environments, with an installer that also fixes
libadwaita and Flatpak applications.
</p>

<div>
<p class="eyebrow">Setup</p>
<h2>Install the theme</h2>
</div>
</div>

<h3>🚀 Quick Start</h3>
<ol class="timeline">
<li>
<strong>Download the theme</strong> <span class="item-badge">Step 1</span>
<p>Clone the repository and change into its root folder.</p>
<pre><code>git clone https://github.com/HELIX-Origin/Hentai-Senpai-Multi-DE-Theme.git
cd Hentai-Senpai-Multi-DE-Theme</code></pre>
</li>
<li>
<strong>Install with recommended fixes</strong> <span class="item-badge">Step 2</span>
<p>Installs the theme along with the GTK4, Flatpak and dock fixes.</p>
<pre><code>./install.sh --update -l -f --dock</code></pre>
</li>
<li>
<strong>Apply the theme</strong> <span class="item-badge">Step 3</span>
<p>Activates the theme for your current desktop environment.</p>
<pre><code>./scripts/apply.sh</code></pre>
</li>
</ol>

<h3>Installation Options</h3>

| Option | Short | Description |
| :--- | :--- | :--- |
| `--update` | | Update/reinstall theme |
| `--uninstall` | `-u` | Remove theme |
| `--libadwaita` | `-l` | Fix GTK4/libadwaita apps |
| `--flatpak` | `-f` | Fix Flatpak apps |
| `--dock [TYPE]` | | Dock theme (transparent/solid) |
| `--wallpapers` | `-w` | Install wallpapers |
{: .surfaces-table}

</section>
