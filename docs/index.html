About

Hentai-Senpai is a beautiful dark GTK theme based on Orchis with the elegant Nord color palette.

It provides complete theming for GTK 2, 3 and 4, GNOME Shell, window decorations and docks across multiple desktop environments, with an installer that also fixes libadwaita and Flatpak applications.

Install

🚀

Quick Start

  1. Download the theme

    Step 1

    Clone the repository and change into its root folder.

    git clone https://github.com/HELIX-Origin/Hentai-Senpai-Multi-DE-Theme.git
cd Hentai-Senpai-Multi-DE-Theme

  2. Install with recommended fixes

    Step 2

    Installs the theme along with the GTK4, Flatpak and dock fixes.

    ./install.sh --update -l -f --dock

  3. Apply the theme

    Step 3

    Activates the theme for your current desktop environment.

    ./scripts/apply.sh

Installation Options

OptionShortDescription
--updateUpdate/reinstall theme
--uninstall-uRemove theme
--libadwaita-lFix GTK4/libadwaita apps
--flatpak-fFix Flatpak apps
--dock [TYPE]Dock theme (transparent/solid)
--wallpapers-wInstall wallpapers
🔧

Quick Fixes

  1. GTK4 apps not themed?

    Run ./install.sh -l, then log out and back in.

  2. Flatpak apps not themed?

    Run ./install.sh -f, then restart Flatpak apps.

  3. Dock not styled?

    Run ./install.sh --dock transparent or --dock solid.

📋

Requirements

  2. GNOME Shell 40+ (for GNOME users)

  3. Bash 4.0+
